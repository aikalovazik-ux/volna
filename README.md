# Волна — простой мессенджер

Аккаунты, личные чаты, каналы (пишет только владелец), голосовые сообщения и видеосообщения до 30 секунд. Тёмная тема, удобно с телефона.

## Запуск на своём компьютере

1. Установите Node.js (версия 18 или новее) с nodejs.org.
2. В папке проекта выполните:

```
npm install
npm start
```

3. Откройте http://localhost:3000, зарегистрируйте двух пользователей в разных вкладках (одну лучше в режиме инкогнито) и пишите друг другу.

Камера и микрофон работают на localhost и на сайтах с https. На обычном http по IP-адресу браузер их заблокирует.

## Выкладка на Render

1. Создайте на github.com пустой репозиторий и загрузите в него файлы проекта (без папок `node_modules` и `data`).
2. На render.com: New → Web Service → выберите репозиторий.
3. Настройки:
   - Build Command: `npm install`
   - Start Command: `npm start`
4. Нажмите Deploy. Через пару минут сайт будет доступен по адресу вида `https://название.onrender.com`.

## Важно знать

- Данные (пользователи, сообщения, голосовые и видео) лежат в папке `data`. На бесплатном тарифе Render эта папка стирается при каждом перезапуске или обновлении сайта. Чтобы данные сохранялись, подключите к сервису диск (Disks) и задайте переменную окружения `DATA_DIR`, равную пути диска, например `/var/data`.
- Бесплатный сервис «засыпает» без посещений, первый заход после паузы занимает около минуты.
- Для настоящего проекта храните данные в базе (например PostgreSQL или Supabase), а файлы в облачном хранилище. Сейчас всё в одном JSON-файле, этого хватает для друзей и тестов.
- Трансляции экрана в проекте нет, её нужно делать отдельно через WebRTC.

## Устройство

- `server.js` — сервер: регистрация и вход, чаты, каналы, загрузка файлов, обмен сообщениями через Socket.IO.
- `public/` — сайт: `index.html`, `style.css`, `app.js`.
